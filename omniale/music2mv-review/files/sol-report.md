# 音乐视频审片报告

审片对象为 sources.json 的全部 10 个 source。时间均以各源视频 0 秒为起点；下面的时间取近似值，关键动作保留了原生帧序列。仅作审片与返修建议，没有修改源素材。

同步结论：**4 段 pass，4 段 revise，无漏项**。综合审片按根因合并为 **6 项修改建议（2 major、4 minor）**，另有 1 项情绪关系观察不计确定缺陷。

使用视频内实际音轨，结合本地 Music Flamingo、Qwen2.5-Omni、Whisper 感知/转写、原声波形和画面时间序列交叉核对。模型曾出现漏听后段琴音、错误乐器描述及超出片长的时码；这些输出没有直接当作事实。起音时间回到解码音频测量，动作回到源画面核对。波形只用来定位起停，不单独用来判断乐器。

[结构化审片结果](review.json)与本报告表达同一组事实；[取证短片清单](evidence_manifest.json)记录每个短片对应的源时间。短片保留源 AAC 原声，无配音替换、音乐替换或变速；短片自身 0 秒应加上清单里的 source_start_s 才是源时间。

### clip_01 — pass

**连续画面：** 男子始终对着话筒；0–2.6秒嘴唇、下颌随短语连续变化，约1.6–2.1秒开口说末段，2.6秒后闭口、低头离开话筒。

### clip_02 — pass

管乐乐句与持续含住吹嘴、分组换指的表演相符，整体可放行。

**原声：** 全段是明亮的管乐旋律及较低的合奏层，无可识别人声。开头有连续较短的音高/发音变化，中段有较长音，约4秒后又进入较密的短音变化。

**判断：** 判断依据是短音变化段与换指活动、长音段与持续吹奏的组合对应，而非只看见乐器。混合声部不能逐一唯一分配给画面中的每个人，也不要求连奏中每个音都出现大动作；未见明显的停吹而主声部仍继续或相反的冲突。

### clip_04 — revise

有吹奏外观，但按阀动作与实际长音/短句的变化缺少稳定对应，尚未达到同步放行要求。

**原声：** 原声为单线、有明确起音和延续的管乐样旋律，无可识别人声。约1.24秒重新起音后，1.3–2.6秒主要保持同一长音；约2.73、3.60、4.12、4.76、5.19秒有新的明显起音/乐句分隔。波形和谐波轨迹支持这些起停定位。

**连续画面：** 男子持续贴住吹嘴。1.25–1.92秒逐帧可见阀上方手指反复抬起、落下、换组合，1.3–2.6秒及3–3.5秒均不只是一次落指后维持长音；后半段也持续类似的小幅快速活动，未呈现与上述发声分组一致的按放节奏。部分阀体被手遮挡，不据此臆算具体指法。

**判断：** 长音可以伴随姿态调整，舌奏也不需要每次移开吹嘴；本项不以这些正常情况判错。问题是反复换指样动作覆盖声音稳定延续段，而实际乐句重起没有形成清晰动作对应。不能仅凭管乐音色加上持小号动作放行；建议按真实音轨重做指法和乐句动作。具体乐器音色在本地感知模型间有分歧，未把“乐器种类错误”作为事实。

**建议：** 按本片原声人工校对整条歌词轨，统一韩语/罗马字写法，修正重复副歌及其他误词，再逐句审校。
