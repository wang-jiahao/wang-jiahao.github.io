# 音乐视频密集审片检查表 v7

这是一套从原片找可核查缺陷的操作指南，不照搬生成模型的偏好总分，不预设每片必有问题。每个结论必须有时间、实际声音／连续画面、正常解释与需改理由；无把握列uncertain。同一Qwen多会话有共同偏差，不能写成人工共识。

## 研究到本任务的映射

| 一手来源 | 借鉴内容 | 在本题的边界 |

| [AVGen-Bench](https://github.com/microsoft/AVGen-Bench) | 视听同步、口型、文字、人脸、音乐、语音、物理和综合语义分开检查 | 指定音高／指定台词等只在确有要求时可验；本题不凭背景配乐缺少某个音高判错 |

| [CAST-Bench](https://arxiv.org/html/2611.05422) | 声源—事件—时间—主体绑定，以及跨镜头事件与身份保留 | 对明确前景表演追踪发声者；MV画外音乐合法，不要求所有声源可见 |

| [SyncReward](https://arxiv.org/html/2610.16338) | 区分声音相关性与时间同步；攻击／接触、起停、事件数量和正常技法 | 不把总均分反推具体错误帧；不把画面乐器当实际听到的声音 |

## 具体检查维度

### AV1 声音内容与发声主体

实际听到的是讲话、歌唱、何种器乐、音效还是背景配乐？当镜头明确在展示前景发声，声音是否来自所指主体，事件种类／数量是否对应？需要先听原声再看归因，避免“看到鼓就听到鼓”。画外配乐、后期歌声、蒙太奇不强求现场拟音；没有导演要求，不因外形／性别推断声线不符。

### AV2 起止、攻击、接触与持续／休止

检查触键／拨弦／击打、口部接触解除、声音新进入、休止与余响。必须排除准备、延音、混响、正常遮挡和另一声源。不能要求每个音符一次大动作；只有可明确对应的前景声源才能据此强判。

### AV3 歌唱／讲话构音

对可见的演唱／讲话核对开闭口、闭唇辅音、圆唇元音、持续高音、呼吸与无声段；检查嘴动而无人声、人声继续而嘴停。按实际片段建立证据，不只说“好像没对上”；画外旁白不是可见嘴型错误。

### AV4 音乐节拍与表演运动

对连续舞蹈、敲击和明显设计成卡点的重复动作，比较动作重心／触地／攻击与清楚的音乐脉冲，检查反复滞后、漂移或动作冻结。容许切分、半拍、慢动作、弱拍设计；不要求每次切镜在鼓点上，不把无舞蹈的叙事镜头缺少律动当错。

### AV5 乐段、能量与剪辑发展的关系

从完整音乐建立主歌／副歌／间奏、配器／强弱变化的可听线索，再检查跨段视觉安排。只提出有具体音画事实、且妨碍既定表达的失配；“副歌没有更炫”不是自动错误。本维度必须带较长上下文，局部窗口只能提线索。

### AV6 歌词含义、情绪与视觉表达

列具体声句／音乐情绪及同期表演／情境，区分矛盾、支持、反讽、回忆、安慰和象征。没有要求逐字演歌词；不能因为悲歌配笑脸就直接定错。有明确关系问题仍可进主分，但必须经独立核验考虑反方，非单人审美偏好。仅局部证据不够则标全局复查。

### V1 人体与面部结构

多余／缺失／融合手指、面孔和肢体断裂、关节不合理、持物手拓扑改变。至少结合连续可见帧排除模糊、遮挡、透视和运动；不能从一张低清单帧强判六指。

### V2 动作、接触与空间相互作用

触物悬空、手穿物体、脚滑／不着地、动作路径跳断、握持与物体受力明显冲突。幻想漂浮可以成立；漂浮时可见吊具是另一项制作残留。物理原则要结合风格，而非把魔法本身当错。

### V3 对象持续性与因果

连续动作中道具凭空消失／重现、数量变化、接触断开、遮挡后变成另一物体。先确认无cut、合理出框／交接／遮挡，不因没看见整条运动路径就断言消失。对比相邻前后帧并标最小区间。

### V4 人物、衣着与环境的时间一致性

连续镜头中脸、衣纹、材质或背景结构不合理漂移；跨镜头只有已建立同一人／同一事件且没有换装／时间跳跃解释时才强判。正常灯光变色、风格化颜色渐变、明确变形转场须作为替代解释。

### V5 字幕与场内文字

分开记录：字幕转写内容错误、显示起止错误、场内文字错字／乱码／笔画不稳定。字幕必须和实际可听声音比对；字幕系统性错误可以是一类根因，但每处不同实例都留时间和证据。不能把正常外语、不承载意义的装饰或虚焦小字当乱码。

### V6 剪辑、技术与制作残留

非意图性的黑帧、花屏、冻结、重复／跳帧、硬拼断续、明显未清理的UI／吊线等。需要源片原样证据；低码率、标注用转码、切段边界、播放器加载失败都不是生成缺陷。正常停格、闪白、快速蒙太奇、音乐尾奏不自动扣分。

### V7 跨镜头空间与事件关系

已经建立的同一动作／物体／场景关系突然不可能衔接；区分穿帮与正常省略剪辑、象征蒙太奇、梦境和回忆。须引用前后两个位置，不从12秒片段编整片剧情。

### A1 可听的技术异常

突兀断音、爆音、非意图性重复或剪接、与画面事件无关的异常声，仅记录实际听到的时刻。没有独立原曲母带，不把歌手唱法、原曲配器或源曲混音归因于MV生成；没有拟音委托，不要求画面每个动作都必须有音效。

## 标注与核验规则

- 先逐窗口细标，AV与视觉两视角独立；每项写criterion_id、音／画事实、需要修改的命题、最强正常解释、源时间和最小复核区间。
- 再用全片概览＋完整音轨独立检查AV5/AV6/V4/V7，建立跨窗证据；细节不得只凭概览强判。
- 合并重叠窗里同一次事件，保留不同位置的实例；不能因都属“生成错误”而合并。事件实例与问题根因分层存储，不按每帧／每个错字刷分。
- 每条命题经3个新会话直接回原片短段核验，至少2票明确接受才成为GT；uncertain保留诊断，不进漏报分母。
- 纯视觉问题不能冒充音画联合问题；统计二者分布。正文不得把原曲已存在的缺点写成生成过程造成。
- 四支素材先用统一协议构造、冻结，再独立Sol/xhigh开发测试。筛选基于确认问题数量、音画覆盖和开发得分，选材偏差如实记录；不叫独立泛化验证。

本检查表是对上述研究的任务化改编，不宣称采用其官方完整评分实现。
