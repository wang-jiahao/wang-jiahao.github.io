# 两支完整MV的独立组合测试

输入仅四片开发筛选中选定的两支完整自然生成MV及各自同源音轨，不包含旧版8个表演候选。筛选使用预先声明的独立问题数/开发分排名和，四片分数全部保留。筛选后另开一次真实Windows Codex CLI / Sol xhigh求解；不能把筛选答案拼接成组合测试答案。

两支均沿用dense-mv-v7的根因匹配、定位、依据和误报判定，按实际源片独立验收，然后合并独立问题计算全题质量F1。每支三份新Qwen3.8-Omni-Flash全模态票，按预定A-A、B-B、C-C形成三份组合总分，取首三份完整有效组合总分的中位数。每根q=0.50+0.25定位+0.25依据，后二项0/0.5/1；总分=100*2*两片匹配q总和/(两片已匹配根数+两片明确误报数+两片GT根数)。逐片分量用于解释，不按电影时长或重复字幕字词加权。这样只有一类问题的影片不会仅因片数占据半数总分。新成立发现须源核验并统一扩展参照，不能当误报；不确定观察不扣为明确误报。

全题根因汇总公式及题面在新组合求解前冻结；四片独立筛选分不追溯更改计算公式。三票属于同模型多上下文共识；不是人工认证或不同模型投票。CPU开发测试，GPU正式验证后补。正常联网、NJU直连，不人为限制执行时长、工具、抽帧或音频。组织者Qwen仅标注/裁判，被测模型可使用本地开源感知工具。API或格式失败不作模型0分。历史v6b混合题和四片筛选分与本次不同输入，不横向当同条件提升/退步。
