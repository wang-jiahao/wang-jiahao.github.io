## 寻镜与混音

通过源片抽帧、切镜检测和本地 faster-whisper 对白索引定位，再逐帧核对盖章、摔杯、监听转场、啤酒箱信号、话筒特写和车顶电弧。source_map.json 按成片顺序记录每条剪辑，入点包含，出点不包含，单位为秒。部分段落用同一个段号对应多条原片镜头，以呈现前后分开的关键动作。

中文旁白采用题面工具提供的 Qwen3-TTS-Flash Ethan 音色。原片对白、环境声和配乐均取自源文件。旁白期压低原片声轨，并为关键效果声保留动态。六处原声按原速保留，独立校正音量，并在两端短淡化。语音合成服务条款独立适用。
