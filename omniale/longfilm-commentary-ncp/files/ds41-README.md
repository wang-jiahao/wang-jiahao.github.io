# 《Trapped (1949)》中文剧情解说成片

## 交付内容

- `commentary.mp4`：完整中文剧情解说成片，H.264 / AAC，854x480、30 fps、17827 帧，总长约 00:09:54.234，含烧录字幕和 6 段英文现场原声。
- `subtitles.srt`：与成片时间轴一致的 UTF-8 外挂字幕，共 203 条；中文单行最长 21 字，原声段采用英文原句加中文翻译。
- `source_map.json`：42 个段落的逐段源片映射，字段含 `segment_id`、成片区间、源片区间、片段时长与源片/成片速度比，覆盖成片全部时长。
- `script.md`：按实际成片时间码整理的 42 段定稿文本、模式、源片窗口及六段原声对白区间。

## 成片与制作方法

全片理解、选镜和剪辑决策均在本地独立完成。制作中使用了整片语音转写、全片 5 秒间隔接触表、逐段关键帧和逐镜头边界核对；42 段均在源片中重新定位并对画面实质内容、动作和原声口型进行检查。成片保留源文件固有的左侧黑边与来源署名，不做裁切或遮盖。

中文旁白由题面默认的 Qwen3-TTS-Flash 服务通过 `tools/tts.py` 合成，未使用真人旁白或外部音乐。旁白段的源片底音压低约 26 dB，TTS 先归一化至约 -20 LUFS，并在每个音频入口和出口加入 80 ms / 120 ms 淡变。六段指定原声恢复前景并做平滑进出。整片最终采用两遍 EBU R128 归一化，实测综合响度约 -17.95 LUFS，真峰值约 -1.99 dBTP。

画面按段落独立重定时后统一为 30 fps，成片源片速度比约为 0.972-1.094，没有用极端变速补时长。字幕在画面下部安全区内烧录：旁白为白色中文；英文原声段为上方金色英文、下方白色中文。外挂 SRT 与烧录内容、时间轴一致。
