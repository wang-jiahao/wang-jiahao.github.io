# 工具、资料与检查

- 源片：`media/source.mp4`，ffprobe 探测 H.264 720×360、AAC、容器时长 986.069 秒。复制到报告后 SHA-256 与原文件一致。视频原声保留。
- 使用 `toolkit/media.py inspect` 和 Qwen3.8-Omni-Flash 分六段观察 0–986 秒音画；输出留在 `_work/S1-reading.json`。模型输出是辅助记录，部分自动解释不可靠，报告中的重点依据原片帧和相关片段回查，不把模型推断作为独立测量。
- `toolkit/media.py frame` / ffmpeg 按指定秒数抽帧；Pillow 制作接触表，人工查看报告所用帧和 Android Central 自拍样张。视频是 720×360，微观图的可辨识程度受原片和编码限制。
- 用 requests 实际打开并保存哔哩哔哩元数据、Android Central 测评、两篇 arXiv 论文 PDF 和评测配图；PyMuPDF 提取论文文字，比较结论的逐字证据保存在 `_work/`。来源与发布者、具体作用及局限见页面参考来源。没有找到足以证明本机驱动电路或透过率的第一手测量，故未将其写成事实。
- `node toolkit/validate_data.mjs output/js/data.js`：通过；8 个片段、5 条来源、3 个锚点，比较条目的两段引文均匹配本地文本。该工具不验证事实真实性。任务说明中提到的 MCP 审核服务未安装，因此没有声称其通过。
- Playwright 使用本机 Chrome，以 `file://` 打开成品：视频 metadata 时长 986.087 秒；静音播放约 0.92 秒；向前跳转至 750 秒、向后跳转至 330 秒；点第 5 段目录后到约 508.47 秒。引用 S1 定位高亮、图片灯箱打开及 Esc 关闭均成功；报告内 10 张图加载成功，无页面脚本错误。桌面 1440×900 和手机 390×844 截图已人工查看，手机页面宽度为 390 px，无横向溢出。截图保存在 `_work/`。
- 研究及核验截至 2026-11-06。网页中的评测观点是当时作者的经验，并非本次对手机进行的实验；论文设备与实验面板均非本机，不能迁移具体数值。
