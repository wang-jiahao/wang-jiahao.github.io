# OmniDR-Bench

[OmniDR-Bench.jsonl](OmniDR-Bench.jsonl) The file contains 50 tasks in UTF-8 JSONL format, with one JSON object per line.

| 字段 / Field | 说明 / Description |
|---|---|
| `id` | 唯一任务 ID / Unique task ID |
| `video_url` | YouTube 或 Bilibili 源视频链接，保留分 P 参数 / Source video URL, including any part parameter |
| `query` | 任务请求 / Task request |
| `rubric` | 完整评分标准与配置 / Complete evaluation criteria and scoring configuration |
