# 角磨机装配动作证据交接

## 交付内容

- `actions.json`：81条可回查事件，右手51条、左手30条；每条含双视角证据区间和可见事实备注。
- `policy.json`：从完整交接录音恢复的最终口径。
- `report.html`：默认列出全部事件，支持手别、动作、对象和文本筛选，以及正面／俯视逐段回放和交接音频回听。
- `README.md`：方法、发现、未知项、打开方式和来源许可。

动作计数：pick_up 20、put_down 7、transfer 6、flip 5、adjust 15、fit 16、fasten 12。双手同时主动操作时以左右两条轨记录同一物理过程，不使用`both`，也不把它解释为两遍装配。

## 方法

1. 对`input/handover.wav`使用本地`large-v3-turbo`与`medium`转写交叉核对，按负责人最后确认恢复口径；操作员未被采纳的省略、合并建议均排除。
2. 前段为`[0,83)`，记录双手的`pick_up`、`transfer`、`adjust`、`fit`、`fasten`、`flip`；后段为`[83,173.8]`，另加`put_down`。单纯扶持始终不记。
3. 以`front.mp4`为主时钟，`top.mp4`同区间互查。两段原片均为1280×720、30fps、5214帧、173.8秒；秒数是按帧复核的近似动作边界，不声称是数据集原标注或绝对帧级真值。
4. 连续同类操作合并换握、找孔和工具往复；明显换动作、换对象或结束后重做才分行。跨83秒的事件按开始时刻所属段处理，不拆分。
5. 只写可见动作。不用遮挡推断内部接合、具体螺钉规格、工具尖端、扭矩或运行安全。

## 主要发现

- 可见过程依次包括轴与机体对位、多个细小件手拧、扳手与螺丝刀旋拧、圆盘总成和环状适配件贴合、齿轮状圆件装配、小副件组合尝试，以及长柄手拧和最终整机放下。
- 前段放下／归还不归档。82.2秒左右开始的橙色螺丝刀放下虽然跨83秒，仍整体按前段排除。
- 85.75–86.0秒圆件由左手转交右手，左右各一条`transfer`；随后右手继续对位和贴合，避免把执行手误并为单一只手。
- 后段工具归还、退回小件和最终双手放下整机均按口径保留；同一次双手操作在左右手轨中成对出现。

## 未知项与保守处理

- 45.6秒左右白色环件已落在灰垫上，属于前段意外掉落，不记`put_down`，也不声称它当时已接合；67.8–68.1秒左手从灰垫清楚拾起该环件。
- 47.6–48.0秒右指接触／拨动灰垫上的长小件，但未见清楚抬离，不另记`pick_up`。66.6–67.0秒左手仅接触红盒边缘，不记红盒取件。
- 83秒翻面时左手主要用于稳定，未单列；107秒左掌位于工具下方，是否接件无法确认，只归档随后可见的主动对位。
- 127–143秒小副件多次相互对位和贴合尝试受手指遮挡，不能断言完成接合；137秒后的左手偶发接触也未扩展成连续动作。
- `small_attachment`统一覆盖看不清的细小紧固件／弹簧／拨件；`adapter_plate`仅表示可见环状适配件。所有`fit`和`fasten`都不是产品质量、扭矩或运行安全结论。

## 可靠打开

保持`output/`与`input/`的相对位置不变，直接用近期Chrome、Edge或Firefox打开`output/report.html`。页面不依赖网络、外部库或导出短片；媒体路径为`../input/front.mp4`、`../input/top.mp4`和`../input/handover.wav`。若浏览器限制本地媒体，可在本题根目录运行`python -m http.server 8000`，再访问`http://localhost:8000/output/report.html`。操作系统需支持原片H.264解码；页面也提供原片和音频直接链接作为回退。
