# 角磨机装配动作证据交接

交付入口：[report.html](report.html)。结构化台账为 [actions.json](actions.json)，最终口头口径为 [policy.json](policy.json)。网页内嵌同一份数据，不需要联网或加载第三方脚本。

## 可靠打开

保留原有目录关系：`output/` 与 `input/` 相邻，`input/` 内保留 `front.mp4`、`top.mp4`、`handover.wav`。无需复制媒体或导出大量短片。

推荐在本任务目录执行：

```powershell
python output/serve_report.py --open
```

也可以在 `output/` 内执行 `python serve_report.py --open`。浏览器地址为 `http://127.0.0.1:8765/output/report.html`。如端口占用，添加 `--port 8766`。服务仅监听本机，支持 HTTP 字节范围请求，适合视频跳转；关闭终端或按 Ctrl+C 可停止。

可直接用 Chrome / Edge 打开 `report.html`；若本地文件媒体策略导致无法播放，使用上述本地服务。网页默认展示全部记录，含未知动作和公开歧义区间观察。筛选不会合并或删除同时发生的左右手事件。

点击每条的“正面”或“双视角”回放；默认附带前后各 0.65 秒，并在区间末尾自动暂停。取消“前后各 0.65 秒”可播放台账原始起止。支持慢速、逐帧、上一条／下一条、整片定位和原片链接。俯视按名义同一时刻联动，不声称已恢复亚秒同步。音频入口另有两段范围、手轨规则、最后确认的回听按钮；音频自己的时间不混入视频动作时间。

## 口径与主要发现

- 最终权限属于负责人。操作员的“仅右手”“不记对位”“全段不记放下”“合并双手”“删除手指旋入”和最后“省略取起”建议均被否决。
- 视频事件开始于 `[0,83)` 秒时，两手均记录取起、转交、翻面、对位调整、插入／贴合、旋拧；排除放下／归还及单纯扶持。从 83 秒至 173.8 秒增加放下／归还。跨界事件按开始时口径处理并保留完整区间。
- 当前台账共 **115 条**：右手 69 条、左手 46 条。含 3 条动作类型为 `null` 的保守观察，其中 2 条位于公开左手歧义排除区。条数是本次视觉归档结果，不是预设目标或正确率保证。
- 前段可见右手取轴并交左手、右手取机体并翻向、两手配合轴对位与插入、齿轮状圆件就位、小件手拧及扳手旋拧、环状适配件转交与套入。之后有多次小件取持、对位、贴合、手指起扣和螺丝刀旋拧。
- 后段较大圆盘总成由左手取出、交给右手，再对位贴合；后续小附件在手中准备并装到机体边缘。末段左手取黑色长柄、对孔、贴入和连续手拧，最后两手共同翻向并放下整体。

## 观察方法与字段约定

只使用本目录的任务说明、两路真实录像、拟制交接音频、公开排除区间及来源许可。未查找或读取原数据集标注、评审资料或现成答案，也未读取其他实验目录。

先用 `ffprobe` 核查两片均为 H.264、1280×720、30fps、5214 帧、173.8 秒。用 OpenCV 按时间顺序制作双视角逐秒总览，再看相邻 0.5 秒画面；取放、交接和小件变化处加密至 0.25 秒并放大局部。分别跟踪解剖左手与右手，全部事件时间统一用 front。俯视用于识别取件来源、对象形状和交接；正面用于回查朝向、插入、手指及工具旋转，未以俯视遮挡代替正面核查。时间给到十分之一秒是方便定位，不代表逐帧测量精度。

交接使用 `local_asr.py` 的 large-v3-turbo 生成通用转写，并用 medium 独立复核范围数字所在的 39–84 秒音频。两次均辨认出 83 秒与 173.8 秒。原始 ASR 有“绚拧／归环”等同音字错误，不能直接当人工校订逐字稿；最终语义与负责人的最后否决已恢复到 policy，关键音频区间在其中列出。

`action` 使用公开七类；无法可靠区分的工具协作动作写 `null`。`object` 记录该手直接操作的对象：工具旋拧以 `screwdriver` / `wrench` 为对象，手指旋拧以所捏的小附件、长轴或长柄为对象。`body` 包含已插轴或已连柄的整体；同一类别的小附件不强行猜规格、螺钉头型、弹簧或拨件细名。`note` 描述可见事实与推断边界。

相同手、动作、对象的连续旋转或工具往复合并。换动作、换对象，或明确结束后重新开始则分开；转交在双方各有一条。两手均主动对位、压合、翻向或放下时分别记录，单纯稳定机体的手不因另一手工作而新增事件。接触、对位和可见压合分别评估，不把接近直接写成安装成功。

每条 `evidence` 同时提供 front / top 的回查窗口，比事件起止各扩展 0.65 秒并限制在视频长度内。`policy_segment` 是按事件开始时间得到的口径。`evaluation_excluded` 仅按公开区间与事件中点计算：左手 `[111,118)`、`[146,150)`，其他手和时间照常保留。这个标记不隐藏记录，也不意味着动作已被可靠判定。

## 未知项与局限

98.5–104.9 秒左手接触工具柄部，无法可靠区分纯稳定和主动施转，动作类型留空。112.3–117.8 秒、146.9–149.6 秒左手协作同样留空；后两条按公开规则排除。小附件局部受手指、机体和低分辨率遮挡，细分类统一用公开上位类别。按压、转动的存在不能证明螺纹内部接合、齿轮啮合、最终锁止、扭矩、产品合格或运行安全。

录像与音频均为给定素材：交接是后期合成语音，不能当现场工具声音。两片共享名义时钟，未对亚秒视角偏移做估计。

真实浏览器 UI 实测未完成：本机浏览器控制接口在设置中禁用，随后 Windows 窗口控制因无法可靠识别当前浏览器 URL 而主动停止。没有绕过该限制。交付另做 JSON／口径一致性、脚本语法、页面 DOM 交互模拟和 HTTP 媒体范围校验；结果见 `review/validation.json`。DOM 模拟不能替代浏览器对 H.264 的真实解码与自动播放策略验证。

## 文件与复现

`review/build_actions.py` 保存本次人工视觉观察及导出逻辑；`review/build_report.py` 将 JSON 数据内嵌到网页。若修改台账，应重新执行：

```powershell
python output/review/build_actions.py
python output/review/build_report.py
python output/review/validate_delivery.py
```

`review/` 还保留顺序核查联系表、局部放大图、通用 ASR 转写和 QA 记录。它们只用于证据复核，不是数据集参考标注。生成图有裁切、缩小和时间戳；原视频未作本次改动。

20 项页面 DOM 交互模拟已通过，包括组合筛选、空结果、恢复全部、同时转交不去重、事件跳转、区间自动停止、单帧步进及最终政策回听。验证日志已保留；如需重跑该项，可先执行 `npm ci --prefix output/review/qa_tools`，再执行 `node output/review/dom_qa.cjs`。这项依赖仅用于验证，打开报告和运行媒体服务不依赖 Node 或 npm。
