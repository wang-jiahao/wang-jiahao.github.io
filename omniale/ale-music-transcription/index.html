一、任务定义

委托场景：把一段管弦乐录音写成可以继续排练、编辑与播放的总谱，而不是只抄出主旋律或找到现成谱。

求解输入：139.492 秒原始 MP3；未更换为原工程或参考 MIDI。

材料提供内容
录音139.492 秒立体声 MP3。播放器使用求解时的原始文件。
BriefDorico Prelude / Akinola，140 BPM；27 个乐器条目，附谱号与零基 GM 程序号。
任务从录音恢复所有声部的音高、节奏、力度、奏法和表情，设置配器，交付可继续编辑与播放的完整总谱。
交付PDF、MIDI、原生 MuseScore 工程或 MusicXML，以及显示谱表的编辑器截图；文件须表示同一音乐作品。
独立作答约束允许通用自动转谱工具，禁止现成答案。禁止检索或使用本曲既有总谱、MIDI、原始工程、安装包示例和旧测试答案；保持联网。

四、失败分析

1. 导出一致性通过，音乐内容没有还原

378 次估计起音都能在候选 MIDI 中复现，所以一致性为 1；但参考乐谱的音高、节奏、力度与配器匹配仍很低。模型自检回答的是“我写的文件是否相符”，没有验证“这些音符是否就是录音中的音乐”。

3. 工具调通没有消除分离与归属难题

轨迹记录了模型安装、权重下载、T5 库兼容修复、半音预处理偏差修正，以及谱表声部超限修复。它最终把文件导出流程做通，但从密集混音中恢复持续音、颤音与相近音色的能力仍不足。

这些是轨迹中观察到的困难；没有做控制实验，不能断言某一预处理错误单独造成了全部失分。

4. 把答案来源审查加入能力评测

首轮取用原谱使独立能力测量失效。重测使用全新容器、无宿主目录挂载，评分参考仅在作答结束后暂存。搜索、命令、脚本和权重审查未发现本曲现成答案的检索或使用。

Agent 披露通用搜索中出现过无关 benchmark 摘要，称未打开或使用；保留这一披露。轨迹审查不等于完整网络抓包或预训练数据审计。这是 Agent 加通用转谱工具的测试，不能称作 GPT 原生音频能力。
