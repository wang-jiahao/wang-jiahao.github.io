# 本轮感知方式：Qwen 原生音视频

这是本轮实验补充约束，优先于TASK.md中一般性的感知工具许可；其余输入、内容要求、交付和验收均不变。

- 请主要依靠你自己的原生音视频理解：用Qwen Code的read_file直接读取原片或切出的有声视频，必要时直接读取WAV音轨复听。字幕应由你根据实际声音和画面独立理解后写出。
- 可以使用ffmpeg/ffprobe、Python、图像处理等普通媒体工具做切片、抽帧、无语义的静音检测、降噪、慢放，以及字幕校验和MKV封装。处理后的音视频可继续用原生read_file读取。最终成片仍须复制原始音视频流。
- 本轮不调用、安装、下载或加载其他ASR、语音翻译、VLM或Omni模型，也不使用现有模型权重、其他实验转写、其他模型交付或外部感知API。不要让Whisper、Qwen-ASR、Fun-ASR、FireRed、Dolphin等替你识别声音。也不要通过MCP、子Agent或脚本请求另一模型代答。
- 正常联网。可以查通用方言知识或媒体工具文档；不能按原片特征、语料编号反查原文、译文、字幕或答案。网络不作为获取本题转写的渠道。
- 输入只有当前目录的TASK.md、input/source.mp4和input/segments.json。不要访问当前工作目录以外的评测、素材答案、实验记录、模型缓存或其他案例文件；可以使用正常软件依赖。
- 画面与声音都应实际查看。建议先按已知边界逐段读取有声视频，再对听不清的局部直接读取音轨。没有把握的内容按TASK.md标注[无法确认]，不凭画面背景或想当然补全。
- 不设人为执行时限。完成output/的三个交付文件并自行做技术检查后结束，简要列出原生音视频读取方式和使用过的普通媒体工具。
