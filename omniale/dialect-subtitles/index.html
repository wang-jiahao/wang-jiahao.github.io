多方言视频的普通话字幕制作

给Agent一段六种方言的真人视频，为不懂方言的观众制作普通话字幕。既要听清讲了什么，也要保留人物、否定、数量和时间关系，最终交付带可切换字幕的成片。

6种方言 · 24段 · 2分53秒普通话字幕 + 成片独立运行 · 联网

一、任务定义

24段独立表达按顺序拼成一条有声视频，附每段的起止时间与方言标签。Agent需要将方言转换成自然的简体普通话，再制作字幕与成片；每段独立，不拼成连续故事。

实际测试输入

一条视频，一份片段清单

source.mp4：

segments.json：S001—S024的起止时间与方言标签。

不提供方言原文、普通话译文、参考字幕或源语料编号。画面保留真人口型与表情，交付需保留原声与画面。

实验设置与交付

项目设置
方言覆盖吴语/温州永嘉、粤语/广西龙州、闽南语/汕头潮阳、客家话/龙岩新罗、湘语/冷水江、赣语/江西万安；每地4段。
运行环境Windows Codex CLI；Sol / xhigh / NJU Link，DeepSeek V4.1 Flash / max / DashScope。相同CPU工具环境、独立目录与会话，正常联网，可安装依赖、下载本地感知模型和查询通用方言知识，不设执行预算。
运行边界不反查本题原片对应的原文或答案，不读取其他模型交付与评测文件；不用其他通用对话或Omni云端API代答。
实际交付zh-CN.srt普通话字幕、subtitled.mkv带字幕轨的成片、segments.json片段到字幕的映射。保留原音视频流，字幕可切换；无法确认的局部可明确标出。
验收标准：语义90 + 组织5 + 交付5

六种方言等权，每种方言内各片段等权。语义按关系命题匹配，接受等价普通话改写，每项得0、0.5或1分；独立的错误或无据新增断言计入误报，重复错误只计一次。

片段语义F1 = 2TP / (G + TP + FP)，再按方言等权换算为90分。空答不获内容分。参考依据是语保原有方言原文与普通话译文；来源字段有差异时接受来源支持的不同表述。

字幕每条最多2行，每行22个非空白字符，阅读速度不超过每秒9字；边界容差0.25秒。程序检查SRT、片段映射、MKV、原音视频流及内嵌字幕一致性。

三、运行轨迹

两次运行都先提取音轨，再反复调用本地感知模型。Sol用时57分36秒，DeepSeek用时2小时21分59秒；耗时包含工具安装、模型下载与复核。每个模型均只展示一次完整求解。
