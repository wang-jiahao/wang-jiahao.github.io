# Caption event recall v2
GT construction follows the user testset: contiguous source segmentation, dense visual/audio logs with visual anchors, chronological lossless merge, three atomic event categories. Qwen3.8-Omni-Flash authors all stages; no Gemini calls. Audio is classified into speech/music/sfx. Fixed GT is generated before solver and never edited from the solver answer.
Each GT event receives0/1 semantic match. Audio requires audible content; synergy accepts local semantic association, no magic conjunction or physical-causality requirement. All caption fields count. Exact speech quotation is unnecessary if meaning matches. Alternative valid scene edges and useful context accepted; no narrow IoU. Wrong-scene descriptions cannot hit. Primary score is within-target event-count recall, then equal mean across6targets. Final score is arithmetic mean of3complete Terra-high ballots. Missing/invalid votes cause a retry or evaluation error, never array padding or automatic0. No null vote or interval. No organizer source-review score overrides. Classes absent from a target are N/A. Models/platform failures are unscored. Category and speech/music/sfx recalls reported separately.
