# 长片中文深度解说成片

你是一名专业影视解说编导与剪辑师。请基于给定的完整电影文件 `input/source.mp4`，独立制作一部 **8–12 分钟** 的中文剧情解说成片，面向**从未看过原片的新观众**（允许剧透）。成片需要把片中多条交错人物线的核心事实、知情错位与因果转折讲得准确透彻，同时做到**剪辑声画严丝合缝、原声引述真实可听、人物指代清晰不穿帮、视听节奏富有感染力**。

给定原片为独立剧情长片《Valkaama》（2010，导演 Tim Baumann），本测试版本全长 `5593.600` 秒（约 93 分 14 秒），英语对白，Michael Georgi 配乐。请严格以本文件实际音视频内容为唯一依据，不得用网络梗概或早期剧本设定替代核实或脑补原片未呈现的事实。允许正常联网、安装媒体工具、使用本地 ASR、抽帧、OCR、镜头切分与 TTS（也可自行换用表现力更好的 TTS）。**电影理解、文稿撰写、选镜定位与混音剪辑决策必须由你独立完成，严禁调用外部通用大语言模型或多模态模型代看电影、代审剧情或代写脚本。**

## 编导与剪辑职责

1. **多线叙事整合与事实准确度**：
   - 理清各主要人物的身份关系、过往羁绊、出行目的与交汇过程，向新观众讲明白整个故事的起因、推进与结局。
   - 准确把握**知情边界与信息差**：区分角色在特定时刻真正知道什么、隐瞒或编造了什么，以及不同人物在同一空间或不同阶段是真正照面还是擦肩而过；不要把角色的谎言、自我辩解或主观憧憬当成影片证实的客观事实。
   - 关注**纯视觉与非对白叙事证据**：片中大量关键动机与转折由无对白画面承载（如电脑屏幕内容、纸面文字、随身信物、交接物件、销毁动作、肢体冲突细节与终场状态）。凡是旁白提到的具体动作、物件、话语归属与结局举动，必须与原片真实音画一致，切勿张冠李戴或凭空添油加醋。

2. **严格的镜头—旁白同步对应（拒绝敷衍垫画）**：
   - 当旁白描述某一具体人物、关键动作、线索物件或情绪转折时，**同一时刻的画面必须呈现支撑该陈述的真实镜头**（允许合理的反应镜头或前后因果衔接，一般旅途与环境过场允许蒙太奇）。
   - **避免常见剪辑穿帮**：不要在旁白主语说甲角色时切入陌生配角或乙角色的单人镜头造成身份误认；不要只切动作前后的站立、走路、背影或发呆垫画而把核心动作本身剪丢；不要让旁白与关键视觉动作明显抢跑或滞后数秒，也不要出现旁白情绪与画面人物状态相反的情况。

3. **多处叙事原声留白与混音质感**：
   - 全片至少在 **3 处不同叙事阶段** 留出无中文旁白遮盖的**原片现场原声窗口**（每处建议 3–10 秒），让原片角色的关键对白或情绪爆发直接推动叙事，并配以准确的中文翻译字幕或紧邻的上下文引导。
   - 中文旁白段落与原片音轨之间需做好平滑的音量闪避（Ducking）与衔接，避免原片残留外语对白顶撞中文旁白，避免切镜时音乐突兀跳断。

默认 TTS 调用方式：`python tools/tts.py --text-file narration.txt --out narration.wav`（环境与配音说明详见 `ENVIRONMENT.md`，署名与 CC BY-SA 3.0 许可要求详见 `SOURCES.md`）。

## 必需交付清单（放入 `submission/`）

1. `commentary.mp4`：实际可播放的 **8–12 分钟**（480–720 秒，容差 ±10 秒）完整解说成片，包含画面、中文旁白、保留的原片叙事原声及清晰同步的中文字幕（推荐烧录硬字幕；同时保留外挂字幕文件）。
2. `script.md`：按成片时间顺序整理的完整中文解说文稿，显式标注各处保留原声的起止位置与内容。
3. `subtitles.srt`：与 `commentary.mp4` 严格同步的 UTF-8 中文字幕文件（单行建议不超过 22 个汉字，阅读速率适中）。
4. `source_map.json`：成片镜头与原片时间轴的完整映射表（JSON 数组或含 `segments` 键的对象），每条记录包含 `output_start_s`, `output_end_s`, `source_start_s`, `source_end_s`（片头片尾黑场或自制字卡可将源时间设为 `null`）。
5. `README.md`：制作方法、所用工具、自检说明，以及符合 `SOURCES.md` 要求的原片改编署名与许可声明。

## 评分与门槛

总分 **100 分** = **叙事与事实准确度（40 分）** + **选材定位与逐段声画一致性（35 分）** + **成片视听制作体验（25 分）**。公开评分维度与验收方法详见 `SCORING.md`。无独立格式加分：无可播放成片记 0 分；存在严重交付违规时总分上限封顶为 **60 分**。
