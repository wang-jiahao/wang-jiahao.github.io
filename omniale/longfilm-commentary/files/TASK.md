# 北行遗信：长片中文深度解说成片

你是一名专业影视解说编导与剪辑师。请将 `input/source.mp4` 独立制作成一部 **8–12 分钟** 的中文剧情解说成片，面向**从未看过原片的新观众**（允许剧透）。成片不仅要把三条交错人物线的核心事实、知情错位与因果转折讲得准确透彻，还必须做到**剪辑声画严丝合缝、原声引述真实可听、人物指代清晰不穿帮、视听节奏富有感染力**。

给定原片为 Tim Baumann 执导的独立剧情长片《Valkaama》（2010），本测试版本全长 `5593.600` 秒（约 93 分 14 秒），英语对白，Michael Georgi 配乐。请严格以本文件实际音视频内容为唯一依据，不得用网络梗概或早期剧本设定脑补原片未呈现的事实。允许正常联网、安装媒体工具、使用本地 ASR、抽帧、OCR、镜头切分与 TTS（也可自行换用表现力更好的 TTS）。**电影理解、文稿撰写、选镜定位与混音剪辑决策必须由你独立完成，严禁调用外部通用大语言模型或多模态模型代看电影、代审剧情或代写脚本。**

## 编导与剪辑要求

1. **三条人物线的交汇与信息差**：
   - 向新观众清楚交代旅人 Lasse 与 Runa（及弟弟 Max）的相处与告别、轮椅青年 Ari 的绝望与自称 Lazarus 的 Magnus 的介入、Runa 的寻人调查、Lasse 与 Magnus 的北上同行，以及北方废墟与湖畔的终局。
   - 准确刻画人物之间的**知情边界与谎言**：谁在何时隐瞒了什么、谁在同一空间擦肩或躲藏却互不相识、谁在何时已经获知死讯，避免把角色的单方面说辞、欺骗或乌托邦幻想当成影片客观证实的事实。
   - **忠于原片的动作与细节**：凡是旁白明确提到的具体物件、书信/字条、屏幕聊天、电话、销毁痕迹或肢体冲突（如谁持刀、谁推挡、谁喊出了关键台词、结局人物手里究竟有没有拿东西），必须与原片画面和声音完全一致，不得添油加醋或张冠李戴。

2. **严格的镜头—旁白对应（拒绝敷衍垫画）**：
   - 当旁白描述某一具体动作、线索物、电脑/纸面信息、情绪反应或冲突过程时，**同一时刻的画面必须呈现支撑该陈述的真实镜头**（允许合理的反应镜头或前后因果衔接，一般背景与旅途过场允许蒙太奇）。
   - **严禁声画穿帮**：不能在旁白说甲角色做某事时切入陌生配角/乙角色的特写造成身份误导；不能只切动作前后的站立/走路/发呆垫画而把核心动作本身剪丢；不能让旁白比关键视觉动作抢跑或滞后数秒导致视听脱节。

3. **多处叙事原声保留与混音质感**：
   - 全片至少在 **3 处不同叙事阶段** 留出无中文旁白遮盖的**原片现场原声窗口**（每处建议 3–10 秒），让原片角色的关键对白或情绪爆发直接承担叙事推进作用，并配以准确的中文翻译字幕或紧邻的上下文引导。
   - 中文旁白段落与原片音轨之间需做好平滑的音量闪避（Ducking）与过渡，避免原片未消干净的对白与中文旁白互相顶撞，也避免切镜时背景音乐突兀跳断。

default TTS 调用方式：`python tools/tts.py --text-file narration.txt --out narration.wav`（环境与配音说明详见 `ENVIRONMENT.md`，署名与 CC BY-SA 3.0 许可要求详见 `SOURCES.md`）。

## 必需交付清单（放入 `submission/`）

1. `commentary.mp4`：实际可播放的 **8–12 分钟**（480–720 秒，容差 ±10 秒）完整解说成片，包含画面、中文旁白、保留的原片叙事原声及清晰同步的中文字幕（推荐烧录硬字幕；同时保留外挂字幕文件）。
2. `script.md`：按成片时间顺序整理的完整中文解说文稿，显式标注各处保留原声的起止位置与原声内容。
3. `subtitles.srt`：与 `commentary.mp4` 严格同步的 UTF-8 中文字幕文件（单行建议不超过 22 个汉字，阅读速率适中）。
4. `source_map.json`：成片镜头与原片时间轴的完整映射表（JSON 数组或含 `segments` 键的对象），每条记录包含 `output_start_s`, `output_end_s`, `source_start_s`, `source_end_s`（片头片尾黑场或自制字卡可将源时间设为 `null`）。
5. `README.md`：制作方法、所用工具、自检说明，以及符合 `SOURCES.md` 要求的原片改编署名与许可声明。

## 评分构成（满分 100 分，交付合规门槛封顶）

总分 = **叙事与事实准确度（40 分）** + **选材定位与逐段声画一致性（35 分）** + **成片视听制作体验（25 分）**。
具体评分细则与计算方式完全公开于 `SCORING.md`。无独立格式加分：若无有效可播放成片则记 0 分；若成片可播放但存在严重交付违规（时长超出 8–12 分钟 ±10 秒、无音轨或无画面、无可读中文字幕、缺少可解析的文稿或源片映射且无法恢复），最终总分封顶为 **60 分**。
