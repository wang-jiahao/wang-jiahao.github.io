# 赴约的人

《Valkaama》（2010）中文剧情解说，含完整结局。播放 `commentary.mp4` 即可，中文字幕已烧入画面，不必另开字幕轨。

拉塞约阿里在第四次日出时见面，赴约的却是一个叫得出拉塞名字的陌生人。这部重剪从阿里交出的钥匙开始，沿一封借邮箱寄出的信、一个留给孩子的娃娃、另一封藏在照片之间的信，追踪拉塞、露娜和马格努斯为什么会抵达同一个湖边。

## 制作与自检

- 仅使用题给的 `input/source.mp4`。以 OpenCV 建立全片画面索引，再对邮件、娃娃、钥匙与小瓶的交接、照片墙、营火、林间冲突和最后的湖边逐处回看。英语 ASR 用于定位对白，不用转录补写画面没有呈现的动作。
- 独立编写分镜与中文文稿，按人物第一次出现、物件交接方向和各人当时所知来选镜。用题给的 `tools/tts.py`、Ethan 音色合成 62 段中文旁白，再用本地 faster-whisper 对齐已经写好的文稿，按真实发音安排字幕与镜头切点。
- 12 处原声对白合计 75.16 秒。原声段不铺中文旁白，左上标“现场原声”，译文为暖黄色；中文旁白字幕为白色。以 NumPy、SciPy、SoundFile 处理原片底声、交叉淡化和电平，Pillow 排字，OpenCV 与 FFmpeg 输出成片。没有另加音乐、音效、剧照或其他外部素材。
- 终版已通过 FFmpeg 全片音视频解码。两轨时长均为 671.880 秒；综合响度 −18.8 LUFS，真峰值 −1.0 dBTP。217 条字幕均按帧起止，无重叠，最长一行 22 个字符（含标点）。
- 映射从第 0 帧连续覆盖全部 16,797 帧。逐一抽取 160 个区间的中帧，与源时间对应帧比较：避开字卡和字幕后，按 BT.709 亮度换算，最大片段平均绝对误差为 0.83（0–255 刻度）。
