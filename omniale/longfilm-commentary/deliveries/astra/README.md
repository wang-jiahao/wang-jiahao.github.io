# 北行遗信

《Valkaama》中文剧情解说，含剧透。播放 `commentary.mp4` 即可观看，中文字幕已烧入画面：白色为旁白，暖色为原片对白译文。无需另行加载字幕。

## 文件与时间轴

- `commentary.mp4`：10 分 48.52 秒，1280 × 720，25 fps，H.264 画面及 48 kHz 立体声 AAC。原片画面等比置于版心，不裁掉人物、纸面或屏幕边缘。
- `script.md`：依成片顺序列出各段旁白、七处原声的起止时间、英语内容和中文译文。
- `subtitles.srt`：UTF-8 外挂中文字幕，与烧录版共用同一组语音起止点。对白行另标说话人。
- `source_map.json`：129 段可连续回溯的视频区间，按成片播放顺序排列。秒数对应 25 fps 时间轴，区间含起点、不含终点，片尾湖面也有源片位置。

## 制作

仅使用给定 `input/source.mp4` 的画面、对白、环境声与配乐。先用 OpenCV、Pillow 制作带时间码的接触表，再对邮件便签、玩偶交接、公寓藏身处、信件、营火、坡地和终场加密取帧。本地 faster-whisper 提供英语对白检索和局部复核，疑难处再对照说话人和前后反应镜头。未使用外部剧情梗概、剧本、字幕或通用模型代做电影理解、撰稿与剪辑。

旁白以“谁在什么时候知道什么”为线索，从露娜读信切入，分六章。拉塞心中的社区、马格努斯的谎言与影片实际呈现的事分开叙述。湖边只交代两人回去、一人留下，不替淡出后的人物添加行动。

中文稿分段交给题面 `tools/tts.py`，使用 Ethan 音色；按实际 WAV 时长及中文语音对齐结果编排字幕，以人工确定的动作节点定镜头。源片连续解码按帧取段，原速组接。旁白下方压低原音的中央声部并短渐变，以本版片尾配乐轻垫切镜；七处原声窗口撤去中文旁白及额外音乐，只保留对应原片混音。使用 Python、NumPy、SciPy、SoundFile、OpenCV、FFmpeg / libass、ffprobe 编排、混音、编码与核验。

## 自检

- 成片共 16,213 帧；片长 648.52 秒。源片映射从首帧至尾帧连续覆盖，无空档。
- 194 条字幕顺序递增、无时间重叠；外挂单行最长 22 字符（含标点和说话人），中位阅读速度约 5.3 字符/秒。
- 原声窗口逐处与源片同期音频做相关性核对，并检查语音起止及译文。保留电话中的停顿，全段不插中文解释。
- 在最终封装文件上检查完整音视频解码、分段中点画面、字幕排版及片尾署名。最终混音约 −15.0 LUFS，真峰值约 −0.9 dBTP。
