# 给第一次观看者的成片评分

总分为剧情50＋制作50，格式没有独立分，严重不符最高60。

按成片给第一次观看者的信息判定。文稿、选镜表仅用于定位和恢复交付，不能替实际听看加分。每项充分/部分/未实现对应满分/一半/零；未知、源片冲突或不可靠时点必须先补同一证据，不能记成模型错误。每项写清实际成片位置或经完整观察确认的遗漏。

| 项目 | 分值 | 看片问题 |
|---|---:|---|
| F1 人物关系 | 5 | 能否认出成年人物与往事中人物的联系、他们现在的关系？接受等价译名和清楚的外观说明。 |
| F2 知情范围 | 5 | 能否区分谁实际经历旧案、谁后来才听说、别人又以为谁知道？准确内容不要求每句加“可能”。 |
| F3 事件与责任 | 5 | 能否理解旧案、被处刑者与最后冲突的主要事实？角色自辩不自动替代原片整体呈现。 |
| C1 求助与误解 | 5 | 为什么归乡者去求助，对方为何作出另一种解释，这怎样改变了对他的安排？ |
| C2 托尼的选择 | 5 | 能否理解托尼受到的压力、她怎样配合或坦白，以及归乡者听后为什么改变行动？不要求法条、刑期数字或全部餐厅对白。 |
| C3 旧案与控制 | 5 | 往事怎样影响现在的关系？能否理解玛莎的解释及其局限，不替她或其他人强定唯一心理动机？ |
| C4 最后选择 | 5 | 归乡者如何面对伤害、救人或离开的机会？其他人的选择怎样把故事推向结局？ |
| N1 成年入口 | 5 | 成片以成年归乡者的接触与发现为主要入口，新观众能理解他此刻的处境与行动目的吗？片头危机预告允许。 |
| N2 逐步揭示 | 5 | 往事和误会的揭示是否改变观众对早先行动的理解，而非片头列完真相后只报流水账？不同成立的插叙、铺垫和揭示位置均接受。 |
| N3 完整故事 | 5 | 能否跟到主要冲突和结局，并理解人物关系的去向？不为保持悬念省掉必要原因，也不要求保留全部支线。 |
| V1 归乡与求助 | 5 | 成片实际讲述的归乡处境和关键求助行动，有对应行动、反应或结果支撑吗？一般城镇背景可以蒙太奇。 |
| V2 旧案配画 | 5 | 旧案的核心行为或后果有依据，且没有把全知镜头冒充归乡者亲见的回忆吗？不要求某件凶器的唯一名词。 |
| V3 受压与回应 | 5 | 托尼受到安排、坦白或两人决定下一步时，所选画面能支撑实际叙述吗？接受反应与前后呼应。 |
| V4 误会被揭开 | 5 | 成片在改变人物知情理解时，实际用了有意义的对话、反应或前后依据，而非同人物无关垫画吗？ |
| V5 收束行为 | 5 | 最后的伤害、救人、持枪或离开等被讲到的关键行为有对应画面支持吗？只考实际作出的断言，不要求保留每次动作。 |
| P1 重点分配 | 5 | 时长是否用在改变理解的转折，避免反复讲相同信息或跳过不可缺的原因？快慢本身不扣分。 |
| P2 镜头衔接 | 5 | 切换时期、地点和人物时，新观众有足够线索和时间看懂吗？不要求固定转场或时码卡。 |
| A1 叙事原声 | 2.5 | 至少一处实际可辨的原声承担了叙事意义，并有中文帮助理解吗？允许不同场景和台词。 |
| A2 留出听觉空间 | 2.5 | 原声、旁白和停顿的安排是否让关键信息来得及被听懂？同一处原声缺失已在A1计分时，不在此重复扣。 |
| A3 中文旁白 | 2.5 | 实际旁白听清、断句与重音适合场景吗？不以采用TTS或某种音色本身扣分。 |
| A4 声部转接 | 2.5 | 全片音量、环境声与声部切换是否舒适连贯？不能只靠响度参数给满分。 |
| T1 可读同步 | 2.5 | 实际呈现的中文字幕是否同步、可读，正常播放时读得完？ |
| T2 外语帮助 | 2.5 | 实际被采用的重要外语，其中文解释或字幕是否准确传达语义和语境？不要求未选台词逐句翻译。 |

一个问题只按其实际独立损害计分。错误归因可影响事实；只有另外造成选择不明、配画冲突等具体问题，才影响相应项。揭示顺序不合委托不等于所有事实都错；有依据的结局解读不按唯一措辞判错。道具细节、数字、专名、每句对白、某个唯一镜头与固定揭示秒数均不是隐藏必答清单。
