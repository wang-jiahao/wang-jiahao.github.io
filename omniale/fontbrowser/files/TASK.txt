# 网页复刻

有人把一个线上页面过了一遍录给你，你照着把它做出来。

要求：

1. 输出一个能直接在浏览器里打开的站点，入口是 `output/site/index.html`。
2. 视觉上尽量还原：布局、配色、字号、间距、控件尺寸和位置。
3. 录屏里演示过的交互都要能用。
4. 讲解里提到但录屏画面上看不出来的行为和参数，也要做对。
5. 只做页面顶部到大约 1200 像素高的范围，再往下不用做。
6. 不要联网找这个页面的原始代码或线上版本，只用给你的材料。
   只在当前工作目录内工作。

材料在 `./materials/`：

- `recording.mp4` —— 录屏，带讲解语音，约三分半。

没有给你字体文件。各张卡片的样张用系统里有的不同字体、或者 CSS 通用字族
（serif / sans-serif / monospace / cursive）区分开就行。

交付写到 `./output/`：

- `output/site/` —— 做好的站点。入口必须是 `output/site/index.html`，
  其余文件怎么组织随你。
- `output/notes.md` —— 简要写下你从讲解里听到的、但录屏画面上看不出来的
  行为和参数，以及你是怎么实现的。
