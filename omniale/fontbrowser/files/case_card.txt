# OmniALE 案例：看录屏复刻网页（fonts.google.com 字体浏览器）

- **case_id**：`omniale-webrecreate-fontbrowser`
- **分类**：视频复刻网页（平衡型：交互逻辑 ≥ 排版工艺）
- **能力标签**
  - 视觉感知：从录屏里读出三栏布局、控件位置与尺寸
  - 语音感知：从讲解里取出交互**参数**（区间、步长、默认值、匹配语义）
  - 前端实现：把一个真实在用的工具页搭出来
  - 状态逻辑：输入驱动的实时重渲染、滑块、单选组、子串筛选、排序
- **结构难度**：L2，单轮交付但状态机不平凡
- **媒体**：录屏 1 段（214 秒，1440×900，30fps，中文讲解）
- **环境**：E1 纯容器（纯静态站），无需 GPU，**被测模型断网**
- **源页面**：`https://fonts.google.com/`（线上真站）

## 1. 为什么是这个站（候选对比，实测）

A 类（linear.app）考的是排版工艺。B 类要的是**真实交互逻辑**，所以按
「可测控件种类数」挑源站：

| 候选 | 交互种类 | CSS 规则 | 界内节点 | 动画元素 | @media |
|---|---|---|---|---|---|
| **fonts.google.com** | **6** | **1828** | **1100** | 384 | **157** |
| vercel.com/templates | 3 | 412 | 339 | 141 | 11 |
| tailwindcss.com | 3 | 360 | 403 | 259 | 50 |
| raycast.com/store | 1 | 2290 | 251 | 166 | 306 |
| stripe.com/pricing | 1 | 732 | 1110 | 719 | 112 |

gfonts 压倒性胜出：4 个文本输入 / 2 个滑块 / 3 个勾选 / 12 个下拉 /
15 个可展开 / 2 个弹窗。更关键的是它的核心交互**画面看得见、参数只能靠听**。

## 2. 音频承载什么

B 类的音频不是补充描述，而是**参数表**。下面每一条都在讲解里，画面上都定不下来：

| 讲解里说的 | 实测值 | 画面上为什么定不下来 |
|---|---|---|
| 滑块区间、步长、默认值 | 8–300，step 1，默认 40 | 滑块只有 178px 宽，刻度不可见 |
| 样张字号 = 滑块值（1:1） | 96→96px，200→200px | 看得出变大，看不出是 1:1 还是比例缩放 |
| 滑块只管样张，界面字号不动 | body 恒 16px，卡片名字恒 16px | 要同时盯两处才看得出，录屏里不会刻意演示 |
| 清空预览框回落到哪 | 回落到《世界人权宣言》第十八条开头 | 一闪而过，且「回落到字体名」同样说得通 |
| 预览文案对**所有**卡片同时生效 | 13/13 张 | 画面只能看到视口内那几张 |
| 搜索是不区分大小写的**子串**匹配 | `rob` → Roboto / Roboto Mono / … | 只演示小写、只演示前缀命中的词，看不出语义 |
| 三个布局按钮是一组**单选** | 同时只有一个 aria-checked | 要连点三次才看得出互斥 |
| 排序下拉的四个选项 | Trending / Most popular / Newest / Name | 下拉展开只有一帧 |
| 各卡片样张字体彼此不同 | 13 种 | 看得出不同，但「必须不同」是约束不是观察 |
| 1024px 以下左栏自动收起 | 卡片 x 从 476 变 112 | 断点数值画面上没有 |

配套静音消融包：`webrecreate_fontbrowser_muted/`（画面逐帧一致，只去音轨）。

## 3. 参考基准

和 A 类同样的做法——基准是**从线上观测固化的静态产物**，不是站点副本：

- `build/capture_ref.py` → `tests/ref_artifacts.json`
  （控件几何 / 卡片 / 每个交互的前后状态 / 字号谱 / 文本表 / 断点）
  + `build/_ref_shots/live_*.png`
- `build/_gfonts_probe*.json`：探针原始记录
- 复刻范围：顶部 **1200px**（原站页高 252,205px，虚拟滚动，必须限界）

关键实测值：

```
预览框   264×156 @(128,120)      滑块 178×44 @(211,294)  min8 max300 step1 val40
搜索框   407×24  @(732,32)       排序 @(1172,40)         布局单选 @(1083/1173/1264,100)
卡片     行布局 904×160 @x=476 单列   网格 440×320 两列
名字 16px  样张字号 = 滑块值      界面字号恒 16px        样张字体 13 种
断点     ≥1280 左栏在，卡片 x=476 ／ ≤1024 左栏收起，卡片 x=112 ／ 390 卡片 358×180
```

## 4. 评分（`tests/verify.py`）

权重：**IFS 0.35 / AFS 0.30 / VFS 0.25 / RSP 0.10**
（比 A 类更偏功能：B 类是平衡型，排版工艺让位给交互逻辑）

| 桶 | 判据数 | 怎么算 |
|---|---|---|
| IFS 交互功能 | 19 | 按录屏轨迹顺序回放，**级联失败**。从「有预览框」一路走到「清空搜索后卡片恢复」 |
| AFS 音频独有 | 14 | 各项独立。全部是参数：区间/步长/默认值/1:1/界面字号不动/回落句/子串语义/单选/排序选项/字体多样性/断点 |
| VFS 视觉保真 | — | 0.35×几何（11 条） + 0.25×结构 + 0.40×rubric judge（14 条二值，judge-then-refute） |
| RSP 响应式 | 6 | 1440 / 1280 / 1024 / 768 / 390 无横向溢出 + 390 下卡片铺满不溢出 |

两个会「看起来对、实际错」的点被专门拆成独立判据：

- **滑块是 1:1 还是比例**：只测一个值分不出来，所以测 96 / 200 / 40 三个点。
- **搜索是子串还是前缀**：另起一页用大写 `ROB` 测，前缀匹配或区分大小写的实现会漏。

## 5. 天花板验证与区分度

手写 oracle（`build/oracle/index.html`，vanilla JS，知道讲解里全部参数），
实测 **95.36**：IFS 19/19、AFS 14/14、几何 11/11、响应式 6/6，
只在结构分掉分（文本覆盖 20%——原站顶部 1200px 有 88 条文本，含大量
筛选标签和书写系统名，录屏里读不全）。

### 单点突变区分度（`build/discrimination.py`）

每次只改 oracle 的**一个**参数（不能一次改多处：实测「清空变空」会让首屏
连样张文字都没有，卡片探测直接失败，把另外几条判据和几何分一起拖下去，
那样测不出每条判据的独立区分力）：

| 突变 | 总分 | Δ | IFS | AFS |
|---|---|---|---|---|
| （oracle） | 95.36 | — | 100.0 | 100.0 |
| 滑块区间/步长/默认值改成 0–100 step5 默认50 | 71.76 | **−23.60** | 63.2 | 64.3 |
| 清空预览框后回落到字体名（而不是默认句） | 72.96 | **−22.40** | 42.1 | 92.9 |
| 预览文案只作用于第一张卡片 | 74.80 | **−20.56** | 47.4 | 92.9 |
| 样张字号按比例缩放，不是 1:1 | 78.48 | **−16.88** | 57.9 | 92.9 |
| 搜索改成只匹配开头 | 89.54 | −5.82 | 89.5 | 92.9 |
| 1024px 下左栏不收起 | 91.55 | −3.81 | 100.0 | 92.9 |
| 界面字号跟着滑块一起变 | 93.22 | −2.14 | 100.0 | 92.9 |
| 所有卡片用同一个字体渲染样张 | 93.22 | −2.14 | 100.0 | 92.9 |

区分力主要来自 IFS 的级联：参数错一个，后面整条轨迹都走不下去。

### 过程中修掉的两个判据缺陷

1. **坏门槛**：原来 IFS 要求「界内可见节点 ≥120」，而线上 612 个节点大半是
   Angular 的包裹层，手写同样内容只有 76 个——这条在惩罚 DOM 嵌套深度，
   不是在惩罚内容缺失。改成 ≥60，结构分里的密度分母也从 300 调到 150。
2. **死判据**：搜索那条原来用 `rob` 做查询，但命中的全是 `Roboto*`，
   **本身就以 rob 开头**，子串实现和前缀实现结果一模一样——实测扣分 **0.00**。
   换成 `sans`（只有子串才命中 Open Sans / Noto Sans），扣分变成 5.82。
3. **过严判据**：布局单选原来强制要 ARIA 状态；讲解只说「同时只有一个是选中的」，
   用 class + 配色实现同样满足。改成 ARIA 优先、没有 ARIA 时退化成
   「恰好一个配色与众不同」。对照页（只用 class）实测仍是 95.36。

## 7. 复现

```bash
python build/capture_ref.py                        # 固化线上基准（需联网）
python build/make_recording.py                     # 重录演示（需联网）
python tests/verify.py <提交目录>
python tests/verify.py build/oracle --no-judge      # 天花板自检
bash /d/omniale_runs/run_case_offline.sh <case_dir> codex gpt-6.1-sol g61sol xhigh
```

交给模型的只有 `task/TASK.md`（约 800 字节）+ `task/materials/recording.mp4`。
不给字体文件——讲解里明确说了用系统字体或通用字族把各卡片区分开。

> 注：原站开了 Trusted Types CSP，录屏脚本里合成光标不能用 `innerHTML`，
> 改用 `createElementNS` 搭 SVG。
