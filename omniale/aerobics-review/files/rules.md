# 冻结动作目录与辨别术语

本次采用FIG官方规则站当前家族总表的代码、名称和基础价值。以下为八个家族的199条代码目录，非本批视频的动作答案。判断以完整示范为准，不把动作本身腿的回环误当成额外身体转体。

- Flair：分腿全旋，以手臂依次支撑，双腿分开绕身体运行。附加TURN指在全旋之外的身体转向；相同的起止朝向不能证明中间没有附加整周转体。
- Helicopter：直升机，从分腿坐开始，由交叉腿带动、以上背承托的旋转，再转换至支撑姿态。不能因结束同为俯撑就与Flair混同。
- Push-up：俯撑结束。Wenson：一条腿置于同侧上臂区域的支撑姿态；需要看脚腿与手臂关系，不能只看躯干低位。Split：纵劈叉结束。
- 1/1为360°，1/2为180°；AIRBORNE强调腾空；TURN、TWIST、SPINDLE按目录所列动作区分，不互换代码。

本题使用名义动作类型及基础价值，不重新裁定执行细扣或动作完成质量。不同视角或同型重复在同一编号单元内只登记一个类型。
