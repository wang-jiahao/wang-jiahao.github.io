# 任务说明：纯代码人声编曲与多场景叙事 MV 创作（*Watching the Rain Fall*）

你是一名集音乐制作人、编曲师、混音师、美术导演与创意技术工程师于一身的创作者。请基于 `input/` 目录下给定的一条**无伴奏纯人声干声**（`input/vocals.wav`，90.00 秒）与**纯文本歌词**（`input/lyrics.txt`，无任何时间戳、BPM、调性或和弦标注），**不借助任何外部音频采样/循环包、外部照片/位图/视频或音视频生成模型**，从零纯靠代码完成整首歌曲的**和声分析、多乐器编曲、发行级立体声混音，以及多场景纯代码叙事 MV 渲染**，并交付可完整复现的工程与成品。

---

## 一、输入素材清单（均在 `input/` 目录）

1. **`input/vocals.wav`**：90.00 秒、48 kHz 立体声无伴奏主唱干声（未提供 BPM、调性、和弦走向与段落切点；且真实人声演唱可能包含细腻的乐句呼吸与微速度起伏）。你必须自行通过本地音频分析与语音对齐工具推断主调、音阶、节奏律动、逐拍节拍网格、情感段落边界与逐词演唱时刻。
2. **`input/lyrics.txt`**：该 90.00 秒片段内演唱的英文完整歌词文本（无时间戳）。
3. **`input/runtime/audio/`**：离线内置的 `fluidsynth.exe`（含所需 DLL）、通用多乐器音色库 `FluidR3_GM.sf2`（MIT）与立式钢琴音色库 `UprightPianoKW-20220221.sf2`（CC0）。
4. **`input/runtime/gsap/`**：离线内置的 `gsap@3.14.1` 核心与动画插件，可配合 HTML/SVG/Canvas/WebGL 渲染工程使用。

## 二、核心创作与工程要求

### 1. 音乐分析与纯代码多乐器编曲（`submission/accompaniment.wav`）
- **调性与和声适配**：根据 `input/vocals.wav` 准确判断主调、音阶及随乐句推进的动态和声走向（和弦不能一成不变，更不可与人声主旋律产生刺耳碰撞）。
- **节拍律动与结构递进**：跟随人声真实速度与微节奏变化构建多声部纯代码编曲（例如鼓组/打击乐、贝斯、吉他/钢琴和弦织体、弦乐/氛围铺底与副歌华彩等），呈现清晰的**引子/主歌（克制、留白）→ 预副歌（推进蓄力）→ 副歌高潮（饱满情绪释放）**层次变化，避免机械重复单调的 4 小节循环。
- **纯代码音色合成**：允许编写 Python/JS MIDI 编曲脚本调用 `input/runtime/audio/fluidsynth.exe` 与内置 `.sf2` 音色库渲染，也允许结合纯代码 DSP 合成或 WebAudio；**严禁包含任何干声泄漏**（`accompaniment.wav` 不得混入原人声），**严禁使用外部预制音频 loop、现成采样包或任何音乐生成模型**。

### 2. 发行级立体声混音与母带（`submission/mix.wav`）
- **原声完整保留**：必须原汁原味保留 `input/vocals.wav` 的音高与时间轴对齐，不得擅自移调、变速或裁剪歌词。
- **响度、人声清晰度与空间感**：将人声与自主编曲混合为符合现代流媒体标准的 48 kHz 立体声成品（目标综合响度约 `-14 LUFS` 区间、留有安全真峰值余量且零削波、保持合理动态范围）；通过合理的声部平衡、频段避让（如在 `1–4 kHz` 人声核心清晰度频段避免伴奏遮蔽）与自然声像宽度，确保唱词字字清晰、声场自然无反相抵消。

### 3. 多场景纯代码叙事 MV（`submission/mv.mp4` + `submission/project/`）
- **100% 纯代码视效**：通过 HTML/CSS/SVG/Canvas/Three.js + Playwright Chromium（或其他纯代码渲染器）构建并渲染 **1920×1080、30 fps、`yuv420p`、含 48 kHz 立体声 AAC 音轨** 的成片视频，音轨须与 `submission/mix.wav` 严格一致。严禁导入外部照片/视频/位图或内联 `data:image/(png|jpg|webp...)` 位图。
- **真正的多场景视觉世界切换（拒绝单调房间与纯频谱壁纸）**：围绕歌词意象（暴风雨过境、灰烬中的回望、书信寄托、雨落释怀等）设计有作者性的叙事画面、角色/景物运动、镜头语言与清晰无遮挡的动态歌词排版；**不同音乐段落必须切换至截然不同的视觉场景世界与构图调度**（而非仅在同一静态房间内微调滤镜，更不能仅仅做一张黑底跳动的音频频谱图或简单波形）。
- **音画双重同步**：视觉动态峰值与场景切换应紧扣音乐节拍与段落边界，同时与人声演唱开闭口/乐句情绪起伏形成清晰可见的同步响应。
