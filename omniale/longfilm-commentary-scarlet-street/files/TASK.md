# 长片非线性多镜对照精准寻镜与成片制作（Narration-Conditioned Production · v2 加难版）

你是一名专业电影剪辑师与视听制作总监。本次任务采用**低开放性、严格可核查**的真实后期制作委托（对应 AgentDirector 的 Narration-Conditioned Production 范式）：主编已经把全片的 **42 段定稿脚本，其中 38 段中文旁白、4 段必留原声对白（`S09`, `S11`, `S25`, `S36`）** 全部拍板写定，放在 `input/script_plan.json` 与 `input/script.md` 中，**但刻意隐去了所有原片时间戳**。

请注意本版采**非线性倒叙与跨时空母题对照结构**：部分段落从片尾倒叙切入，部分段落则在 12–16 秒内要求 **2 个指定子镜头顺次对照（`shot_structure` 明确标注 `先A后B`）**——你不能假设 42 段按原片时间单调递增，也不能靠一镜到底的对话空镜蒙混过关！

给定完整源片 `input/source.mp4` 为 1945 年黑色电影《Scarlet Street》（导演 Fritz Lang，制片 Walter Wanger 与 Fritz Lang，配乐 Hans J. Salter），全长 `6086.480` 秒（约 101 分 26 秒），英语对白。你的核心职责是**独立看懂整部 101 分钟原片，为全部 42 个段落精准找回与文稿叙述高度一致的原始动作镜头、跨时空对照镜头与原声片段，合成忠实于定稿脚本的中文旁白、制作双语分化字幕、完成无顶撞闪避混音与专业多镜节奏剪辑，最终渲染交付一部完整可播的 6–12 分钟解说成片**。

允许正常联网、安装媒体工具、使用本地 ASR、抽帧、OCR、镜头切分与 TTS。**但所有电影理解、精密寻镜、对照切镜、对拍与混音决策必须由你独立完成，严禁调用外部通用大语言模型或多模态模型代看电影、代找镜头或代审成片。**

## 你的核心制作职责（严格按定稿执行）

1. **严格忠实执行 42 段定稿脚本（禁止删段或擅自改写）**：
   - `input/script_plan.json` 共包含 42 个严格有序段落（`S01`–`S42`），且每段标明 `shot_structure`：
     - **38 段 `narration`**：按顺序逐字忠实合成中文旁白（仅允许极其微小的数字读法顺口，绝不能增删核心事实、改写人名或偷换因果）。
       - 标为 **`单拍动作`** 的段落：精确匹配该段所描述的具体微动作、道具或反应镜头；
       - 标为 **`2 镜连贯动作（先A后B）`** 或 **`2 镜跨时空对照（先A后B）`** 的段落：**必须切实剪入 A 镜头与 B 镜头两段真实画面，按“先 A 后 B”顺次与旁白前半句、后半句紧扣同步**，严禁偷懒只用单个长镜头代替两镜对照，也严禁颠倒 A/B 顺序。
     - **4 段 `original_audio`**（`S09`, `S11`, `S25`, `S36`）：**必须完整、干净地保留原片对应的现场英文原声对白**，绝不允许使用中文旁白压盖（需让英文台词在成片里清晰可被听清并匹配中文翻译字幕）。
2. **精确多拍寻镜与 `segment_id` 显式映射**：
   - 你需要自己通过抽帧看图与声画定位，从 101 分钟源片里精确定位每个 `S01`–`S42` 描述的**确切动作与对照子镜头区间**，确保所选源片时间 `[source_start_s, source_end_s]` 在画面上真正呈现对应情节并与旁白句在 **1.5 秒内同步**，且不通过极端加速倍率作弊。
   - `submission/source_map.json` 必须为每条剪辑片段显式标注 `segment_id`（`"S01"` 到 `"S42"`）、`output_start_s`, `output_end_s`, `source_start_s`, `source_end_s`。对于 2 镜段落，请按成片播出先后依次录入同 `segment_id` 的两条对应原片区间记录！**注：评估程序会抽查渲染帧（含多镜对照的各自子镜）与 `source_map.json` 所报源片时间戳的像素一致性，严禁虚报源片时间戳！**
3. **专业音画混音与技术合规**：
   - 中文旁白默认通过 `python tools/tts.py --text-file narration.txt --out narration.wav` 调用本机语音服务合成（详见 `ENVIRONMENT.md`）。旁白时压低原片声轨；4 处 `original_audio` 窗口恢复干净饱满的原片声轨并平滑进出。
   - 成片总长控制在 **6–12 分钟（360–720 秒）**；整体综合响度控制在 **−24 至 −14 LUFS**；单行字幕不超过 **22 个汉字**，旁白字幕与原声英文字幕/中文翻译在样式与色彩上清晰区分；切镜密度与停顿节奏自然（5–40 镜/分钟，禁止机械等长切块）。

## 必需交付清单（放入 `submission/`）

1. `commentary.mp4`：可正常解码播放的 **360–720 秒** 完整解说成片，含正确画面、中文旁白、4 处清晰英文原声及同步烧录硬字幕。
2. `subtitles.srt`：与成片时间轴完全一致的 UTF-8 外挂字幕文件（包含全部定稿旁白文本及原声翻译，单行 ≤ 22 字）。
3. `source_map.json`：覆盖成片 85% 以上时长的逐镜映射表，每条均须含 `segment_id` (`"S01"`–`"S42"`), `output_start_s`, `output_end_s`, `source_start_s`, `source_end_s`。
4. `script.md`：按成片实际时间码整理的全 42 段定稿文稿与原声窗口对照表。
5. `README.md`：简要记录寻镜、跨时空对照与混音方法，并完整保留符合 `SOURCES.md` 要求的原片署名、片源及版本说明。
