# Skeletal Animation Reproduction

Use Blender to rig and animate the provided character so it reproduces the body motion shown in `reference.mp4`.

Official input:
- `Singing.obj`
- `Singing.mtl`
- `reference.mp4`

Required submission:
- Save a playable Blender scene to `output/submission/final.blend`
- Render and save a matching preview video to `output/submission/preview.mp4`

Constraints:
- Focus on body motion only. Face and lip sync are not evaluated in v1.
- The submitted `preview.mp4` and the animation replayed from `final.blend` must both reproduce the supplied body motion.
- Your Blender file must contain the actual rig and animation that produce the submitted preview.
- The watermark in the supplied reference video is not part of the target body motion.
